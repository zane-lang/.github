# Support

Need help with Zane? Here's where to look.

## Documentation

- **Language specification** — [zane-lang/spec](https://github.com/zane-lang/spec)
- **Documentation** — [zane-lang/docs](https://github.com/zane-lang/docs)
- **Website** — [zane-lang/website](https://github.com/zane-lang/website)
- **Coda configuration format** — [zane-lang/coda](https://github.com/zane-lang/coda)

## Questions and discussion

- Open a **discussion** or an **issue** on the repository most relevant to your
  question. For general or cross‑cutting questions, the
  [spec](https://github.com/zane-lang/spec) repository is a good default.
- Search existing issues first — your question may already be answered.

## Reporting bugs

Use the **bug report** issue template on the relevant repository. Include a
minimal reproduction, the version or commit you're on, and what you expected to
happen.

## Security issues

Do **not** file public issues for security problems. See
[SECURITY.md](SECURITY.md) for how to report them privately.
