# .github

This is the organization‑level `.github` repository for
[**Zane**](https://github.com/zane-lang). It holds shared, org‑wide defaults
that GitHub applies across every Zane repository that doesn't provide its own:

- [`profile/README.md`](profile/README.md) — the public
  [organization profile](https://github.com/zane-lang) page.
- [`CODE_OF_CONDUCT.md`](CODE_OF_CONDUCT.md) — the code of conduct for all Zane
  repositories.
- [`CONTRIBUTING.md`](CONTRIBUTING.md) — how to contribute across the ecosystem.
- [`SECURITY.md`](SECURITY.md) — how to report security vulnerabilities.
- [`SUPPORT.md`](SUPPORT.md) — where to get help.
- [`.github/ISSUE_TEMPLATE/`](.github/ISSUE_TEMPLATE) — default issue forms.
- [`.github/PULL_REQUEST_TEMPLATE.md`](.github/PULL_REQUEST_TEMPLATE.md) — the
  default pull‑request template.

Any individual repository can override these by providing its own copy of the
corresponding file.

See [`roadmap.md`](roadmap.md) for the high‑level project roadmap.
